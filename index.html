Adaptive Social Presence Chatbot

A research prototype exploring how conversational style should respond to context. No real emotion model or language model is connected.

Interaction controls

Adaptive mode starts at moderate social presence. If your message contains explicit frustration cues, it switches to a calmer, more direct style. This is a transparent keyword demonstration, not reliable emotion detection.

This control lets you test the rule without having to disclose personal information.

Handoff is simulated for this prototype; no adviser is contacted.

What the prototype does

  • Compares three fixed social-presence levels.
  • Adaptive rule selects a restrained style for explicit frustration cues.
  • Shows the selected style and reason.
  • Lets the user override the style at any time.
Scope: local front-end simulation; no persistent memory, account, external data, or human participant study.
